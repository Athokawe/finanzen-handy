Finanzen verbinden

Die App liest deine Zahlen direkt aus deinem privaten GitHub-Repo Athokawe/finanzen. Dafür braucht sie einmal einen eigenen, eng begrenzten Schlüssel (ein „Token“). Den legst du so am iPhone an:

  1. In Safari github.com öffnen und anmelden.
  2. Diesen Link antippen (öffnet direkt das Formular für einen neuen Schlüssel): github.com/settings/personal-access-tokens/new
    Umweg ohne Link: Settings → Menü oben → ganz unten Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: Finanzen Handy
    Expiration: 1 Jahr (Custom → Datum in einem Jahr; oder das längste Angebot).
  4. Repository access: Only select repositories → Athokawe/finanzen auswählen. Nur dieses eine Repo!
  5. Permissions → Repository permissions:
    • Contents: Read-only
    • Actions: Read and write
    • Metadata: Read-only (wird automatisch gesetzt)
    Alles andere bleibt auf „No access“.
  6. Unten Generate token tippen und den Token (beginnt mit github_pat_) kopieren.
  7. Hierher zurück, unten einfügen und Verbinden tippen.

Der Token bleibt nur auf diesem iPhone – verschlüsselt mit deiner PIN. Er wird nie angezeigt, nie verschickt (außer direkt an GitHub) und nie in diesem Repo gespeichert. „Abmelden“ löscht ihn wieder.
