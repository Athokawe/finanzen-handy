# Finanz-App – Handy-Ansicht

Web-App (zum Home-Bildschirm des iPhones hinzufügbar) für die private Finanz-App.

**Dieses Repo enthält nur die Anzeige und die Knöpfe – keine Daten, keine Schlüssel.**

- Die Zahlen liegen ausschließlich im privaten Repo der Finanz-App.
- Die App liest sie direkt auf dem Handy mit einem persönlichen, eng begrenzten GitHub-Schlüssel des Besitzers. Der Schlüssel wird nur auf dem Gerät gespeichert und nie hier abgelegt.
- Schaltbefehle gehen als Cloud-Aufträge an das private Repo und brauchen dort weiterhin eine ausdrückliche Bestätigung („JA“).

Ohne diesen Schlüssel zeigt die Seite nichts an.
